## 응답 바디

### 속성

| 속성명 | 타입 | 설명 |
| --- | --- | --- |
| `userId` | `Long` | 회원의 고유 식별자(ID) |
| `oauthProvider` | `String` | 회원이 로그인한 OAuth 제공자 (예: `KAKAO`, `GOOGLE`) |
| `email` | `String` | 회원의 이메일 주소 |
| `nickname` | `String` | 회원의 닉네임 |
| `userStatus` | `String` | 회원의 현재 상태 (예: `ACTIVE`, `INACTIVE`) |
| `createdAt` | `String (LocalDateTime)` | 회원 계정이 생성된 일시 (ISO-8601 형식) |

```sql
UserResponse
├── userId : Long
├── oauthProvider : String
├── email : String
├── nickname : String
├── userStatus : String
└── createdAt : String (LocalDateTime)
```
