# 거래내역 목록 조회

Method: GET
URL: /ledger/trades
도메인: 거래원장
상세 설명: 순수 거래내역을 조건별로 조회

### `GET /api/ledger/trades?from=&to=&securityId=&accountId=`

모든 필터 선택, 조합 가능. 페이지네이션 적용.

**요청 헤더**

- `Authorization: Bearer {accessToken}`

**쿼리 파라미터**

- `from` (date, optional)
- `to` (date, optional)
- `securityId` (integer, optional)
- `accountId` (integer, optional)
- `page` (integer, optional, default 0)
- `size` (integer, optional, default 20)

**응답 바디** — 공통 페이지네이션 포맷의 `content[]` 항목:

| 속성         | 타입              | 필수 | 설명        |
| ------------ | ----------------- | ---- | ----------- |
| tradeId      | integer           | O    | 거래 식별자 |
| accountId    | integer           | O    | 계좌 ID     |
| securityId   | integer           | O    | 종목 ID     |
| securityName | string            | O    | 종목명      |
| tradeSide    | string(enum)      | O    | `BUY`       | `SELL` |
| quantity     | integer           | O    | 거래 수량   |
| unitPrice    | number            | O    | 체결 단가   |
| tradedAt     | string(date-time) | O    | 거래 일시   |
