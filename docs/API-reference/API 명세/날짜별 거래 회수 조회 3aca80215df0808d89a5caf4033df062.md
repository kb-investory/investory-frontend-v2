# 날짜별 거래 회수 조회

Method: GET
URL: /ledger/activity/calendar
도메인: 거래원장
상세 설명: 날짜별 거래 건수(홈화면 잔디용)

홈 화면 활동 잔디용 날짜별 거래 건수 (색상 단계 변환은 프론트 책임)

**요청 헤더**

- `Authorization: Bearer {accessToken}`

**쿼리 파라미터**

- `year` (integer, required)
- `month` (integer, required)

**응답 바디**

| 속성         | 타입         | 필수 | 설명      |
| ------------ | ------------ | ---- | --------- |
| activityDate | string(date) | O    | 활동 날짜 |
| tradeCount   | integer      | O    | 거래 건수 |

json

```json
{
  "type": "array",
  "items": {
    "type": "object",
    "properties": {
      "activityDate": { "type": "string", "format": "date" },
      "tradeCount": { "type": "integer" }
    },
    "required": ["activityDate", "tradeCount"]
  }
}
```
