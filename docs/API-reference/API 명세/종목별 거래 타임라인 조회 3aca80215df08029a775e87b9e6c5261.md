# 종목별 거래 타임라인 조회

Method: GET
URL: /journal/trades
도메인: 투자일지

```
GET /journal/trades
```

특정 종목의 사용자 거래내역을 시간순으로 조회합니다. 거래별 판단 근거가 있다면 함께 반환합니다.

# 요청 형식

## 요청 헤더

| 속성            | 자료형   | 필수 | 설명                                    |
| --------------- | -------- | ---- | --------------------------------------- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |

## URL 파라미터

- 없음

예시 URL:

```
GET /journal/trades?securityId=101&startDate=2026-01-01&endDate=2026-07-29&page=0&size=20
```

## 쿼리 파라미터

| 속성         | 자료형         | 필수 | 설명                     |
| ------------ | -------------- | ---- | ------------------------ |
| `securityId` | `integer`      | 필수 | 조회할 종목 식별자       |
| `startDate`  | `string(date)` | 선택 | 조회 시작일              |
| `endDate`    | `string(date)` | 선택 | 조회 종료일              |
| `page`       | `integer`      | 선택 | 페이지 번호. 기본값 `0`  |
| `size`       | `integer`      | 선택 | 페이지 크기. 기본값 `20` |

## 요청 바디

- 없음

## 속성

| 속성                               | 타입                 | 필수 | 설명                          |
| ---------------------------------- | -------------------- | ---- | ----------------------------- |
| `security`                         | `object`             | O    | 조회 대상 종목 정보           |
| `security.securityId`              | `integer`            | O    | 종목 내부 식별자              |
| `security.securityCode`            | `string`             | O    | 6자리 종목코드                |
| `security.securityName`            | `string`             | O    | 종목명                        |
| `security.marketType`              | `string(enum)`       | O    | 시장 구분                     |
| `trades`                           | `array`              | O    | 해당 종목의 사용자 거래 목록  |
| `trades[].tradeId`                 | `integer`            | O    | 거래 식별자                   |
| `trades[].accountId`               | `integer`            | O    | 거래 계좌 식별자              |
| `trades[].accountName`             | `string`             | O    | 거래 계좌 이름                |
| `trades[].tradeSide`               | `string(enum)`       | O    | `BUY` 또는 `SELL`             |
| `trades[].quantity`                | `integer`            | O    | 거래 수량                     |
| `trades[].unitPrice`               | `number`             | O    | 체결 단가                     |
| `trades[].transactionCostAmount`   | `number`             | O    | 수수료와 세금 합계            |
| `trades[].tradedAt`                | `string(date-time)`  | O    | 거래 일시                     |
| `trades[].note`                    | `object` 또는 `null` | O    | 거래 판단 근거                |
| `trades[].note.journalTradeNoteId` | `integer`            | O    | 거래 근거 식별자              |
| `trades[].note.journalId`          | `integer`            | O    | 근거가 작성된 투자일지 식별자 |
| `trades[].note.journalDate`        | `string(date)`       | O    | 근거가 작성된 일지 날짜       |
| `trades[].note.rationaleText`      | `string`             | O    | 판단 근거                     |
| `trades[].note.createdAt`          | `string(date-time)`  | O    | 판단 근거 생성 시각           |
| `trades[].note.updatedAt`          | `string(date-time)`  | O    | 판단 근거 마지막 수정 시각    |
| `page`                             | `integer`            | O    | 현재 페이지 번호              |
| `size`                             | `integer`            | O    | 페이지 크기                   |
| `totalElements`                    | `integer`            | O    | 전체 거래 수                  |
| `totalPages`                       | `integer`            | O    | 전체 페이지 수                |

## 에러

- `400` — 날짜 범위나 페이지 값이 올바르지 않은 경우
- `404` — 조회할 종목이 존재하지 않는 경우
- `401` — 인증 토큰이 유효하지 않은 경우
