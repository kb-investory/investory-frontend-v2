# 증권사 연동 요청

Method: POST
URL: /broker/connections
도메인: 계좌
상세 설명: 목 증권사 인증 후 연결 생성 및 최초 데이터 적재

# 요청 형식

## 요청 헤더

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |
| `Content-Type` | `string` | 필수 | `application/json` |

예시:

```
Authorization: Bearer {accessToken}
Content-Type: application/json
```

## URL 파라미터

- 없음

예시 URL:

```
POST /broker/connections
```

## 쿼리 파라미터

- 없음

## 요청 바디

```
{
  "brokerId":1,
  "loginId":"growth_user",
  "password":"1234"
}
```

### 속성

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `brokerId` | `long` | 필수 | 연동할 증권사 고유 ID |
| `loginId` | `string` | 필수 | 목 증권사 서버에서 사용할 로그인 ID |
| `password` | `string` | 필수 | 목 증권사 서버에서 사용할 비밀번호 |

`loginId`와 `password`는 목 증권사 인증에만 사용하고 Investory DB에는 저장하지 않아.

### JSON Schema

```json
{
  "type":"object",
  "properties": {
    "brokerId": {
      "type":"integer",
      "format":"int64",
      "minimum":1
    },
    "loginId": {
      "type":"string",
      "minLength":1,
      "maxLength":100
    },
    "password": {
      "type":"string",
      "minLength":1,
      "maxLength":100
    }
  },
  "required": ["brokerId","loginId","password"
  ]
}
```

# 응답 형식

## 응답 헤더

```
HTTP/1.1 201 Created
Content-Type: application/json
```

## 응답 바디

```json
{
  "connectionId":15,
  "brokerId":1,
  "brokerCode":"MIRAE",
  "brokerName":"미래에셋증권",
  "connectionStatus":"CONNECTED",
  "connectedAt":"2026-07-29T14:30:00",
  "lastSyncedAt":"2026-07-29T14:30:03",
  "syncResult": {
    "syncBatchId":101,
    "syncStatus":"SUCCESS",
    "accountCount":2,
    "insertedTradeCount":18,
    "holdingCount":5
  }
}
```

### 속성

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `connectionId` | `long` | 필수 | 생성된 증권사 연결 고유 ID |
| `brokerId` | `long` | 필수 | 연동한 증권사 고유 ID |
| `brokerCode` | `string` | 필수 | 증권사 내부 식별 코드 |
| `brokerName` | `string` | 필수 | 증권사 이름 |
| `connectionStatus` | `string` | 필수 | 증권사 연결 상태 |
| `connectedAt` | `datetime` | 필수 | 증권사 연결 완료 시각 |
| `lastSyncedAt` | `datetime` | 선택 | 최초 데이터 동기화 완료 시각 |
| `syncResult` | `object` | 필수 | 최초 데이터 동기화 결과 |
| `syncResult.syncBatchId` | `long` | 필수 | 동기화 작업 고유 ID |
| `syncResult.syncStatus` | `string` | 필수 | 동기화 결과 상태 |
| `syncResult.accountCount` | `integer` | 필수 | 저장된 계좌 수 |
| `syncResult.insertedTradeCount` | `integer` | 필수 | 새로 저장된 거래 수 |
| `syncResult.holdingCount` | `integer` | 필수 | 저장된 보유종목 수 |

### JSON Schema

```json
{
  "type":"object",
  "properties": {
    "connectionId": {
      "type":"integer",
      "format":"int64"
    },
    "brokerId": {
      "type":"integer",
      "format":"int64"
    },
    "brokerCode": {
      "type":"string"
    },
    "brokerName": {
      "type":"string"
    },
    "connectionStatus": {
      "type":"string",
      "enum": ["CONNECTED"
      ]
    },
    "connectedAt": {
      "type":"string",
      "format":"date-time"
    },
    "lastSyncedAt": {
      "type": ["string","null"
      ],
      "format":"date-time"
    },
    "syncResult": {
      "type":"object",
      "properties": {
        "syncBatchId": {
          "type":"integer",
          "format":"int64"
        },
        "syncStatus": {
          "type":"string",
          "enum": ["SUCCESS","FAILED"
          ]
        },
        "accountCount": {
          "type":"integer",
          "minimum":0
        },
        "insertedTradeCount": {
          "type":"integer",
          "minimum":0
        },
        "holdingCount": {
          "type":"integer",
          "minimum":0
        }
      },
      "required": ["syncBatchId","syncStatus","accountCount","insertedTradeCount","holdingCount"
      ]
    }
  },
  "required": ["connectionId","brokerId","brokerCode","brokerName","connectionStatus","connectedAt","syncResult"
  ]
}
```

## 공통 오류 응답 바디

3번부터 9번까지 오류 응답은 아래 형식으로 통일하면 된다.

```json
{
  "code":"BROKER_ACCOUNT_NOT_FOUND",
  "message":"계좌 정보를 찾을 수 없습니다."
}
```

### 속성

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `code` | `string` | 필수 | 서버에서 정의한 오류 코드 |
| `message` | `string` | 필수 | 사용자 또는 개발자에게 전달할 오류 설명 |

### JSON Schema

```json
{
  "type":"object",
  "properties": {
    "code": {
      "type":"string"
    },
    "message": {
      "type":"string"
    }
  },
  "required": ["code","message"
  ]
}
```
