# 단일 주식 상세 조회

Method: GET
URL: /market/securities/{securityId}
도메인: 주식

```
GET /market/securities/{securityId}
```

# 요청 형식

## 요청 헤더

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |

## URL 파라미터

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `securityId` | `long` | 필수 | 조회할 종목의 내부 고유 ID |

예시 URL:

```
GET /market/securities/101
```

## 쿼리 파라미터

- 없음

## 요청 바디

- 없음

# 응답 형식

## 응답 헤더

```
HTTP/1.1 200 OK
Content-Type: application/json
```

### 속성

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `securityId` | `long` | 필수 | 종목 내부 고유 ID |
| `securityCode` | `string` | 필수 | 종목코드 |
| `securityName` | `string` | 필수 | 종목명 |
| `marketType` | `string` | 필수 | 시장 구분 |
| `sectorName` | `string` | 선택 | 업종명 |
| `industryName` | `string` | 선택 | 세부 산업명 |
| `latestPrice` | `object` | 선택 | 가장 최근 일별 시세 |
| `latestPrice.priceDate` | `date` | 필수 | 가격 기준일 |
| `latestPrice.openPrice` | `number` | 필수 | 시가 |
| `latestPrice.highPrice` | `number` | 필수 | 고가 |
| `latestPrice.lowPrice` | `number` | 필수 | 저가 |
| `latestPrice.closePrice` | `number` | 필수 | 종가 |
| `latestPrice.dailyReturnRate` | `number` | 선택 | 전일 대비 등락률 |
| `latestPrice.tradingVolume` | `long` | 선택 | 거래량 |
| `latestPrice.tradingValue` | `long` | 선택 | 거래대금 |
