# 특정 연결의 계좌 목록 조회

Method: GET
URL: /broker/connections/{connectionId}/accounts
도메인: 계좌
상세 설명: 해당 증권사 연결에서 가져온 계좌 목록

# 요청 형식

## 요청 헤더

| 속성            | 자료형   | 필수 | 설명                                    |
| --------------- | -------- | ---- | --------------------------------------- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |

## URL 파라미터

| 속성           | 자료형 | 필수 | 설명                       |
| -------------- | ------ | ---- | -------------------------- |
| `connectionId` | `long` | 필수 | 조회할 증권사 연결 고유 ID |

예시 URL:

```
GET /broker/connections/15/accounts
```

## 쿼리 파라미터

- 없음

## 요청 바디

- 없음

# 응답 형식

## 응답 헤더

```
HTTP/1.1 200 OK
Content-Type: application/json
```

```json
{
  "connectionId": 15,
  "brokerId": 1,
  "brokerName": "미래에셋증권",
  "accounts": []
}
```

### 속성

| 속성                            | 자료형    | 필수 | 설명                           |
| ------------------------------- | --------- | ---- | ------------------------------ |
| `connectionId`                  | `long`    | 필수 | 증권사 연결 고유 ID            |
| `brokerId`                      | `long`    | 필수 | 증권사 고유 ID                 |
| `brokerName`                    | `string`  | 필수 | 증권사 이름                    |
| `accounts`                      | `array`   | 필수 | 해당 연결에서 가져온 계좌 목록 |
| `accounts[].accountId`          | `long`    | 필수 | Investory 내부 계좌 고유 ID    |
| `accounts[].accountNoMasked`    | `string`  | 필수 | 마스킹된 계좌번호              |
| `accounts[].accountName`        | `string`  | 필수 | 계좌 표시 이름                 |
| `accounts[].accountType`        | `string`  | 필수 | 계좌 유형                      |
| `accounts[].holdingCount`       | `integer` | 필수 | 현재 보유 중인 종목 수         |
| `accounts[].totalMarketValue`   | `long`    | 필수 | 계좌의 총 주식 평가금액        |
| `accounts[].totalUnrealizedPnl` | `long`    | 필수 | 계좌의 총 미실현 손익          |
