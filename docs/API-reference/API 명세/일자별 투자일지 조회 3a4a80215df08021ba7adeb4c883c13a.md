# 일자별 투자일지 조회

Method: GET
URL: /journal/entries/on/{date}
도메인: 투자일지

```
GET /journal/entries/on/{date}
```

특정 날짜의 투자일지와 그날 발생한 거래를 조회합니다. 거래별 판단 근거가 있다면 `note`에 포함하고, 없다면 `null`을 반환합니다.

해당 날짜에 일지가 없어도 거래 목록은 반환합니다. 따라서 일지 작성 화면에서도 사용할 수 있습니다.

# 요청 형식

## 요청 헤더

| 속성            | 자료형   | 필수 | 설명                                    |
| --------------- | -------- | ---- | --------------------------------------- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |

## URL 파라미터

| 속성   | 자료형         | 필수 | 설명                           |
| ------ | -------------- | ---- | ------------------------------ |
| `date` | `string(date)` | 필수 | 조회할 날짜. `YYYY-MM-DD` 형식 |

예시 URL:

```
GET /journal/entries/on/2026-07-29
```

## 속성

| 속성                               | 타입                       | 필수 | 설명                                   |
| ---------------------------------- | -------------------------- | ---- | -------------------------------------- |
| `journalDate`                      | `string(date)`             | O    | 조회한 일지 날짜                       |
| `canCreate`                        | `boolean`                  | O    | 해당 날짜에 새 일지를 작성할 수 있는지 |
| `journal`                          | `object` 또는 `null`       | O    | 작성된 투자일지. 없으면 `null`         |
| `journal.journalId`                | `integer`                  | O    | 투자일지 식별자                        |
| `journal.marketThought`            | `string`                   | O    | 시장에 대한 생각                       |
| `journal.marketMood`               | `string(enum)` 또는 `null` | O    | 시장 감정                              |
| `journal.createdAt`                | `string(date-time)`        | O    | 실제 일지 작성 시각                    |
| `journal.updatedAt`                | `string(date-time)`        | O    | 마지막 수정 시각                       |
| `journal.editableUntilAt`          | `string(date-time)`        | O    | 수정 가능 마감 시각                    |
| `journal.isBackfilled`             | `boolean`                  | O    | 과거 일지를 뒤늦게 작성했는지          |
| `journal.isEditable`               | `boolean`                  | O    | 현재 수정할 수 있는지                  |
| `trades`                           | `array`                    | O    | 해당 날짜에 발생한 거래 목록           |
| `trades[].tradeId`                 | `integer`                  | O    | 거래 식별자                            |
| `trades[].securityId`              | `integer`                  | O    | 종목 내부 식별자                       |
| `trades[].securityCode`            | `string`                   | O    | 6자리 종목코드                         |
| `trades[].securityName`            | `string`                   | O    | 종목명                                 |
| `trades[].tradeSide`               | `string(enum)`             | O    | `BUY` 또는 `SELL`                      |
| `trades[].quantity`                | `integer`                  | O    | 거래 수량                              |
| `trades[].unitPrice`               | `number`                   | O    | 체결 단가                              |
| `trades[].tradedAt`                | `string(date-time)`        | O    | 거래 일시                              |
| `trades[].note`                    | `object` 또는 `null`       | O    | 거래 판단 근거. 없으면 `null`          |
| `trades[].note.journalTradeNoteId` | `integer`                  | O    | 거래 근거 식별자                       |
| `trades[].note.rationaleText`      | `string`                   | O    | 사용자가 작성한 판단 근거              |
| `trades[].note.createdAt`          | `string(date-time)`        | O    | 판단 근거 생성 시각                    |
| `trades[].note.updatedAt`          | `string(date-time)`        | O    | 판단 근거 마지막 수정 시각             |

## 계산 기준

```
canCreate
= journal이 없음 AND journalDate <= 오늘(KST)

isBackfilled
= createdAt의 KST 날짜 > journalDate

isEditable
= 현재 시각 < editableUntilAt
```

## 에러

- `400` — 날짜 형식이 올바르지 않은 경우
- `401` — 인증 토큰이 유효하지 않은 경우
