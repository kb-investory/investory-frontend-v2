# 거래내역 상세 조회

Method: GET
URL: /ledger/trades/{tradeId}
도메인: 거래원장
상세 설명: 특정 거래의 체결·계좌·종목 정보를 조회

### `GET /api/ledger/trades/{tradeId}`

**요청 헤더**

- `Authorization: Bearer {accessToken}`

**URL 파라미터**

- `tradeId` (integer, required)

**응답 바디**

| 속성                  | 타입              | 필수 | 설명             |
| --------------------- | ----------------- | ---- | ---------------- |
| tradeId               | integer           | O    | 거래 식별자      |
| accountId             | integer           | O    | 계좌 ID          |
| securityId            | integer           | O    | 종목 ID          |
| securityName          | string            | O    | 종목명           |
| tradeSide             | string(enum)      | O    | `BUY`            | `SELL` |
| quantity              | integer           | O    | 거래 수량        |
| unitPrice             | number            | O    | 체결 단가        |
| transactionCostAmount | number            | O    | 수수료+세금 합계 |
| tradedAt              | string(date-time) | O    | 거래 일시        |

json

```json
{
  "type": "object",
  "properties": {
    "tradeId": { "type": "integer" },
    "accountId": { "type": "integer" },
    "securityId": { "type": "integer" },
    "securityName": { "type": "string" },
    "tradeSide": { "type": "string", "enum": ["BUY", "SELL"] },
    "quantity": { "type": "integer" },
    "unitPrice": { "type": "number" },
    "transactionCostAmount": { "type": "number" },
    "tradedAt": { "type": "string", "format": "date-time" }
  },
  "required": [
    "tradeId",
    "accountId",
    "securityId",
    "securityName",
    "tradeSide",
    "quantity",
    "unitPrice",
    "transactionCostAmount",
    "tradedAt"
  ]
}
```

**에러**

- `404` — 존재하지 않는 `tradeId`
- `403` — 타인 소유 `tradeId`
