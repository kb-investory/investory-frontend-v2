# 로그아웃

Method: POST
URL: /auth/logout
도메인: 인증
상세 설명: Refresh Token 폐기 및 쿠키 삭제

# 요청 형식

## 요청 헤더

```
Cookie: refreshToken=eyJ...
```

Access Token까지 사용자 확인에 사용할 계획이라면 다음 헤더도 받을 수 있다.

```
Authorization: Bearer {accessToken}
```

하지만 Refresh Token 폐기만 수행한다면 쿠키만 있어도 된다.

# 응답 형식

## 성공 응답

### 상태 코드

```json
204 No Content
```

### 응답 헤더

Refresh Token 쿠키를 즉시 만료시켜.

```
Set-Cookie: refreshToken=; HttpOnly; Secure; SameSite=Lax; Path=/auth; Max-Age=0
```

### 응답 바디

- 없음
- JSON Schema 없음

## 처리 과정

```
1. 쿠키에서 Refresh Token 조회
2. 서버에 저장된 Refresh Token 폐기 또는 삭제
3. Refresh Token 쿠키 만료
4. 204 No Content 반환
```

로그아웃은 여러 번 호출돼도 같은 결과가 나오도록 처리하는 게 좋다.

```
Refresh Token이 이미 없거나 폐기됨
→ 오류 대신 204 반환 가능
```

이렇게 하면 프론트는 현재 로그인 상태를 따로 확인하지 않고 로그아웃 API를 안전하게 호출할 수 있다.
