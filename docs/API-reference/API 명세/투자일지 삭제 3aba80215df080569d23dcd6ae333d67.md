# 투자일지 삭제

Method: DELETE
URL: /journal/entries/{journalId}
도메인: 투자일지

```
DELETE /journal/entries/{journalId}
```

투자일지와 해당 일지에 연결된 모든 거래 판단 근거를 삭제합니다.

삭제도 일지 수정 가능 시간 안에서만 허용합니다.

# 요청 형식

## 요청 헤더

| 속성            | 자료형   | 필수 | 설명                                    |
| --------------- | -------- | ---- | --------------------------------------- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |

## URL 파라미터

| 속성        | 자료형    | 필수 | 설명                   |
| ----------- | --------- | ---- | ---------------------- |
| `journalId` | `integer` | 필수 | 삭제할 투자일지 식별자 |

예시 URL:

```
DELETE /journal/entries/305
```

## 구현 노트

```
investment_journals 삭제
→ 연결된 journal_trade_notes 함께 삭제
```

FK에 아래 삭제 정책을 설정할 수 있습니다.

```
ONDELETECASCADE
```

## 에러

- `404` — 존재하지 않거나 타인 소유인 일지
- `409` — 수정·삭제 가능 시간이 지난 일지

> 현재 화면에 삭제 기능이 없다면 이 API는 목록에서 제거해도 됩니다.
