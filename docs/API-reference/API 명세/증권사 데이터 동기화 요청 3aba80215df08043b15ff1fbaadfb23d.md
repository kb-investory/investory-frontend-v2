# 증권사 데이터 동기화 요청

Method: POST
URL: /broker/connections/{connectionId}/sync
도메인: 계좌
상세 설명: 거래내역과 보유현황 재동기화 요청 (account_sync_batches 신규 생성)

# 요청 형식

## 요청 헤더

| 속성            | 자료형   | 필수 | 설명                                    |
| --------------- | -------- | ---- | --------------------------------------- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |

## URL 파라미터

| 속성           | 자료형 | 필수 | 설명                         |
| -------------- | ------ | ---- | ---------------------------- |
| `connectionId` | `long` | 필수 | 동기화할 증권사 연결 고유 ID |

예시 URL:

```
POST /broker/connections/15/sync
```

## 쿼리 파라미터

- 없음

## 요청 바디

- 없음

# 응답 형식

## 응답 헤더

```
HTTP/1.1 200 OK
Content-Type: application/json
```

## 응답 바디

```json
{
  "syncBatchId": 103,
  "connectionId": 15,
  "syncStatus": "SUCCESS",
  "requestedAt": "2026-07-29T15:00:00",
  "completedAt": "2026-07-29T15:00:03",
  "accountCount": 2,
  "insertedTradeCount": 3,
  "skippedTradeCount": 18,
  "holdingCount": 5
}
```

### 속성

| 속성                 | 자료형     | 필수 | 설명                                  |
| -------------------- | ---------- | ---- | ------------------------------------- |
| `syncBatchId`        | `long`     | 필수 | 생성된 동기화 작업 고유 ID            |
| `connectionId`       | `long`     | 필수 | 동기화를 수행한 증권사 연결 ID        |
| `syncStatus`         | `string`   | 필수 | 동기화 결과 상태                      |
| `requestedAt`        | `datetime` | 필수 | 동기화 요청 시각                      |
| `completedAt`        | `datetime` | 선택 | 동기화 완료 시각                      |
| `accountCount`       | `integer`  | 필수 | 동기화된 계좌 수                      |
| `insertedTradeCount` | `integer`  | 필수 | 새로 저장된 거래 수                   |
| `skippedTradeCount`  | `integer`  | 필수 | 중복으로 판단해 저장하지 않은 거래 수 |
| `holdingCount`       | `integer`  | 필수 | 동기화된 현재 보유종목 수             |
