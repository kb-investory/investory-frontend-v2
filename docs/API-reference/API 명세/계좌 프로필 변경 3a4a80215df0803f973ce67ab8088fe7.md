# 계좌 프로필 변경

Method: PATCH
URL: /broker/accounts/{accountId}
도메인: 계좌
상세 설명: Investory 내부 계좌 별칭 변경

# 요청 형식

## 요청 헤더

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |
| `Content-Type` | `string` | 필수 | `application/json` |

## URL 파라미터

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `accountId` | `long` | 필수 | 이름을 변경할 계좌 고유 ID |

예시 URL:

```
PATCH /broker/accounts/25
```

## 쿼리 파라미터

- 없음

## 요청 바디

```json
{
  "accountName":"장기 투자용 계좌"
}
```

### 속성

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `accountName` | `string` | 필수 | Investory에서 사용자에게 표시할 계좌 이름 |

### JSON Schema

```json
{
  "type":"object",
  "properties": {
    "accountName": {
      "type":"string",
      "minLength":1,
      "maxLength":30
    }
  },
  "required": ["accountName"
  ]
}
```

# 응답 형식

## 응답 헤더

```
HTTP/1.1 200 OK
Content-Type: application/json
```

## 응답 바디

```json
{
  "accountId":25,
  "accountNoMasked":"1234-****-5678",
  "accountName":"장기 투자용 계좌",
  "accountType":"STOCK"
}
```

### 속성

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `accountId` | `long` | 필수 | 수정된 계좌 고유 ID |
| `accountNoMasked` | `string` | 필수 | 마스킹된 계좌번호 |
| `accountName` | `string` | 필수 | 변경된 계좌 표시 이름 |
| `accountType` | `string` | 필수 | 계좌 유형 |

### JSON Schema

```json
{
  "type":"object",
  "properties": {
    "accountId": {
      "type":"integer",
      "format":"int64"
    },
    "accountNoMasked": {
      "type":"string"
    },
    "accountName": {
      "type":"string"
    },
    "accountType": {
      "type":"string",
      "enum": ["STOCK","ISA","PENSION"
      ]
    }
  },
  "required": ["accountId","accountNoMasked","accountName","accountType"
  ]
}
```
