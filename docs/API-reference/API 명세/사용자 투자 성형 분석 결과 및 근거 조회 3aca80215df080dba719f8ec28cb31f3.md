# 사용자 투자 성형 분석 결과 및 근거 조회

Method: GET
URL: /tendency/analysis/latest
도메인: 분석

서비스 사용자의 성향을 분석한 결과, 그에 대한 설명과 분석 근거를 반환하는 API

### 속성

| 속성명                          | 타입   | 설명                                         |
| ------------------------------- | ------ | -------------------------------------------- |
| `analysisRunId`                 | Long   | 성향 분석 실행 ID                            |
| `summary`                       | Object | 전체 성향 분석 결과 요약 정보                |
| `summary.combinationSummary`    | String | 6가지 성향 분석 결과를 종합한 전체 설명      |
| `summary.strengthSummary`       | String | 사용자의 투자 성향에서 나타나는 강점 설명    |
| `summary.cautionSummary`        | String | 사용자의 투자 성향에서 주의해야 할 점 설명   |
| `analysisResults`               | Array  | 카테고리별 성향 분석 결과 목록 (총 6개)      |
| `analysisResults[].dimension`   | Object | 분석 대상 성향 카테고리 정보                 |
| `dimension.code`                | String | 성향 분석 항목 코드 (`MARKET_PREFERENCE` 등) |
| `dimension.name`                | String | 성향 분석 항목 이름                          |
| `dimension.description`         | String | 해당 성향 분석 항목에 대한 설명              |
| `analysisResults[].type`        | Object | 해당 카테고리에서 최종 판정된 성향 유형 정보 |
| `type.code`                     | String | 세부 성향 유형 코드                          |
| `type.name`                     | String | 최종 판정된 성향 유형 이름                   |
| `type.description`              | String | 해당 성향 유형에 대한 설명                   |
| `type.rationale`                | Object | 해당 성향으로 판단한 AI 분석 근거 정보       |
| `rationale.summary`             | String | 판단 근거에 대한 요약 설명                   |
| `rationale.items`               | Array  | 세부 판단 근거 목록                          |
| `rationale.items[].type`        | String | 판단 근거 유형 코드                          |
| `rationale.items[].label`       | String | 판단 근거 항목명                             |
| `rationale.items[].value`       | Object | 판단 근거 값                                 |
| `rationale.items[].unit`        | String | 값의 단위 (`PERCENT`, `COUNT` 등)            |
| `rationale.items[].description` | String | 해당 근거에 대한 상세 설명                   |

```sql
analysisRunId
 └── summary
       ├── combinationSummary
       ├── strengthSummary
       └── cautionSummary

 └── analysisResults[]
       └── dimension
             ├── code
             ├── name
             └── description

       └── type
             ├── code
             ├── name
             ├── description
             └── rationale
                    ├── summary
                    └── items[]
                           ├── type
                           ├── label
                           ├── value
                           ├── unit
                           └── description
```
