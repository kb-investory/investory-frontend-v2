### 속성

| 속성명                            | 타입    | 설명                                               |
| --------------------------------- | ------- | -------------------------------------------------- |
| `principleSetId`                  | Long    | 조회된 투자원칙 묶음 ID                            |
| `versionNo`                       | Integer | 현재 적용 중인 투자원칙 버전 번호                  |
| `setStatus`                       | String  | 투자원칙 묶음 상태 (`ACTIVE`, `ARCHIVED`)          |
| `principles`                      | Array   | 해당 투자원칙 묶음에 포함된 개별 투자원칙 목록     |
| `principles[].principleSetItemId` | Long    | 개별 투자원칙 ID                                   |
| `principles[].principleText`      | String  | 사용자가 최종 적용한 투자원칙 내용                 |
| `principles[].origin`             | Object  | 해당 투자원칙의 생성 출처 정보                     |
| `origin.type`                     | String  | 투자원칙 생성 유형 (`AI_RECOMMENDATION`, `DIRECT`) |
| `origin.analysisTypeName`         | String  | AI 추천 기반 원칙인 경우 연결된 성향 유형명        |
| `principles[].sortOrder`          | Integer | 화면에 표시할 투자원칙 순서                        |

```sql
principleSet
 ├── principleSetId
 ├── versionNo
 ├── setStatus
 │
 └── principles[]
       ├── principleSetItemId
       ├── principleText
       ├── origin
       │     ├── type
       │     └── analysisTypeName
       │
       └── sortOrder
```

      "origin": {
        "type": "DIRECT",
        "analysisTypeName": null
      },

    }
  ]
