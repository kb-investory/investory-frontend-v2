# 연동된 증권사 목록 조회

Method: GET
URL: /broker/connections
도메인: 계좌
상세 설명: 로그인 사용자의 증권사 연결 목록

## 요청 형식

## 요청 헤더

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |

요청 예시:

```
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
```

## URL 파라미터

- 없음

예시 URL:

```
GET /broker/connections
```

- 없음

- 없음

### 속성

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `connections` | `array` | 필수 | 사용자가 연동한 증권사 연결 목록 |
| `connections[].connectionId` | `long` | 필수 | 증권사 연결 고유 ID |
| `connections[].brokerId` | `long` | 필수 | 연결된 증권사 고유 ID |
| `connections[].brokerCode` | `string` | 필수 | 증권사 내부 식별 코드 |
| `connections[].brokerName` | `string` | 필수 | 증권사 이름 |
| `connections[].connectionStatus` | `string` | 필수 | 증권사 연결 상태 |
| `connections[].connectedAt` | `datetime` | 선택 | 증권사 연결 완료 시각 |
| `connections[].lastSyncedAt` | `datetime` | 선택 | 마지막 데이터 동기화 완료 시각 |
| `connections[].accountCount` | `integer` | 필수 | 해당 증권사 연결에 속한 계좌 수 |

`connectionStatus` 값:

| 값 | 설명 |
| --- | --- |
| `PENDING` | 연결 처리 중 |
| `CONNECTED` | 연결 완료 |
| `ERROR` | 연결 오류 |
| `DISCONNECTED` | 연결 해제 |
