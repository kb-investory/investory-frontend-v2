# 투자일지 수정

Method: PUT
URL: /journal/entries/{journalId}
도메인: 투자일지

```
PUT /journal/entries/{journalId}
```

투자일지 본문과 거래별 판단 근거의 최종 상태를 함께 수정합니다.

`PUT`이므로 요청의 `tradeNotes` 배열을 **수정 후 남아 있어야 할 전체 판단 근거 목록**으로 처리합니다.

# 요청 형식

## 요청 헤더

| 속성            | 자료형   | 필수 | 설명                                    |
| --------------- | -------- | ---- | --------------------------------------- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |
| `Content-Type`  | `string` | 필수 | `application/json`                      |

## URL 파라미터

| 속성        | 자료형    | 필수 | 설명                   |
| ----------- | --------- | ---- | ---------------------- |
| `journalId` | `integer` | 필수 | 수정할 투자일지 식별자 |

예시 URL:

```
PUT /journal/entries/305
```

## 쿼리 파라미터

- 없음

## 요청 바디

```json
{
  "marketThought": "반도체 업종의 단기 과열 가능성을 주의해야 한다.",
  "marketMood": "CAUTIOUS",
  "tradeNotes": [
    {
      "tradeId": 501,
      "rationaleText": "실적 성장과 HBM 수요를 근거로 매수했다."
    },
    {
      "tradeId": 502,
      "rationaleText": "단기 목표 수익률에 도달하여 매도했다."
    }
  ]
}
```

## 속성

| 속성                         | 타입                       | 필수 | 설명                                       |
| ---------------------------- | -------------------------- | ---- | ------------------------------------------ |
| `marketThought`              | `string`                   | O    | 수정된 시장에 대한 생각                    |
| `marketMood`                 | `string(enum)` 또는 `null` | O    | 수정된 시장 감정. 선택하지 않았다면 `null` |
| `tradeNotes`                 | `array`                    | O    | 수정 후 남길 거래 판단 근거 전체 목록      |
| `tradeNotes[].tradeId`       | `integer`                  | O    | 판단 근거가 연결된 거래 식별자             |
| `tradeNotes[].rationaleText` | `string`                   | O    | 수정된 거래 판단 근거                      |

```
{
  "tradeNotes": []
}
```

를 보내면 해당 일지의 거래별 판단 근거를 모두 제거한다는 뜻입니다.

`journalDate`는 생성 이후 변경할 수 없습니다.

# JSON Schema

```json
{
  "type": "object",
  "properties": {
    "marketThought": {
      "type": "string",
      "minLength": 1,
      "maxLength": 3000
    },
    "marketMood": {
      "type": ["string", "null"],
      "enum": ["CAUTIOUS", "CONFIDENT", "ANXIOUS", "CALM", null]
    },
    "tradeNotes": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "tradeId": {
            "type": "integer",
            "format": "int64"
          },
          "rationaleText": {
            "type": "string",
            "minLength": 1,
            "maxLength": 2000
          }
        },
        "required": ["tradeId", "rationaleText"]
      }
    }
  },
  "required": ["marketThought", "marketMood", "tradeNotes"]
}
```

## 속성

| 속성        | 타입                | 필수 | 설명                   |
| ----------- | ------------------- | ---- | ---------------------- |
| `journalId` | `integer`           | O    | 수정된 투자일지 식별자 |
| `updatedAt` | `string(date-time)` | O    | 수정 완료 시각         |

## 수정 처리 기준

기존 근거:

```
501번 거래 근거
502번 거래 근거
```

수정 요청:

```
501번 거래 근거만 포함
```

처리 결과:

```
501번 근거 → 수정 또는 유지
502번 근거 → 삭제
```

## 에러

### 수정 가능 시간이 지난 경우

```json
{
  "code": "JOURNAL_EDIT_PERIOD_EXPIRED",
  "message": "투자일지 수정 가능 시간이 지났습니다."
}
```

### 존재하지 않거나 타인 소유인 경우

```json
{
  "code": "JOURNAL_NOT_FOUND",
  "message": "투자일지를 찾을 수 없습니다."
}
```
