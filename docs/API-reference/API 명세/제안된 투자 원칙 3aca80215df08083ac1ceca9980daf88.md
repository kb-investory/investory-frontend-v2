## 응답 바디

### 속성

| 속성명 | 타입 | 설명 |
| --- | --- | --- |
| `recommendations` | Array | AI가 생성한 추천 투자원칙 목록 |
| `recommendations[].recommendationId` | Long | 추천 원칙 ID |
| `recommendations[].recommendationText` | String | AI가 제안한 투자원칙 내용 |
| `recommendations[].recommendationReason` | String | 해당 원칙을 추천한 이유 |
| `recommendations[].analysisType` | Object | 해당 추천 원칙이 생성된 성향 분석 정보 |
| `analysisType.code` | String | 성향 유형 코드 |
| `analysisType.name` | String | 성향 유형 이름 |

```sql
principle_recommendations
        |
        +-- recommendationText
        +-- recommendationReason
        |
        +-- analysis_result
                |
                +-- analysis_type
```
