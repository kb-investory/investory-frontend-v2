# 보유 종목 목록 조회

Method: GET
URL: /ledger/holdings
도메인: 거래원장
상세 설명: 최신 보유종목과 평가정보 조회

보유종목 현황. **"현재"와 "과거 특정일"을 같은 엔드포인트로 처리합니다** — `holding_snapshots`는 계좌연동 시점부터 날짜별로 쌓이는 단일 테이블이라, "현재"도 결국 그중 가장 최근 날짜 행일 뿐 별도로 실시간 계산하는 데이터가 아니기 때문입니다.

**요청 헤더**

- `Authorization: Bearer {accessToken}`

**쿼리 파라미터**

- `date` (date, optional) — 생략하면 **가장 최근 스냅샷**(사실상 "오늘")을 반환. 지정하면 그 날짜의 스냅샷을 반환하되, 그 날짜에 정확히 일치하는 행이 없으면 **직전 스냅샷으로 캐리포워드**

**응답 바디**

- 비고: 계좌연동 이후 스냅샷이 하나도 없거나(동기화 직후 배치 미실행 등), 요청한 `date` 이전에 보유 이력 자체가 없으면 404가 아니라 빈 배열 반환

| 속성            | 타입         | 필수 | 설명                                                                                      |
| --------------- | ------------ | ---- | ----------------------------------------------------------------------------------------- |
| asOfDate        | string(date) | O    | 실제 적용된 스냅샷 기준일. `date`를 생략했거나 캐리포워드된 경우 요청한 값과 다를 수 있음 |
| securityId      | integer      | O    | 종목 ID                                                                                   |
| securityName    | string       | O    | 종목명                                                                                    |
| quantity        | integer      | O    | 보유 수량                                                                                 |
| avgCost         | number       | O    | 평균매입단가                                                                              |
| closePrice      | number       | O    | 해당 날짜 종가                                                                            |
| valuationAmount | number       | O    | 평가금액                                                                                  |
| unrealizedPnl   | number       | O    | 평가손익                                                                                  |
| weightPct       | number       | O    | 전체 대비 비중(%) — 서버가 응답 생성 시 계산                                              |

json

```json
{
  "type": "array",
  "items": {
    "type": "object",
    "properties": {
      "asOfDate": { "type": "string", "format": "date" },
      "securityId": { "type": "integer" },
      "securityName": { "type": "string" },
      "quantity": { "type": "integer" },
      "avgCost": { "type": "number" },
      "closePrice": { "type": "number" },
      "valuationAmount": { "type": "number" },
      "unrealizedPnl": { "type": "number" },
      "weightPct": { "type": "number" }
    },
    "required": [
      "asOfDate",
      "securityId",
      "securityName",
      "quantity",
      "avgCost",
      "closePrice",
      "valuationAmount",
      "unrealizedPnl",
      "weightPct"
    ]
  }
}
```

> 설계 노트: 프론트는 "현재 보유현황" 화면과 "특정일 보유현황 조회" 화면에서 이 엔드포인트 하나만 쓰면 됩니다(전자는 `date` 생략, 후자는 지정). 응답에 `asOfDate`가 항상 있으므로, `date`를 생략해서 요청했는데 동기화가 아직 안 돌아 최신 스냅샷이 어제 것이더라도 프론트가 "8/22 기준"처럼 기준일을 표시할 수 있습니다.
