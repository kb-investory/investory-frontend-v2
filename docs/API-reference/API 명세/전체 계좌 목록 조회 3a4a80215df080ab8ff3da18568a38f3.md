# 전체 계좌 목록 조회

Method: GET
URL: /broker/accounts
도메인: 계좌
상세 설명: 연결과 무관하게 로그인 사용자의 전체 증권계좌 조회 (계좌 선택 드롭다운 등)

# 요청 형식

## 요청 헤더

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |

## URL 파라미터

- 없음

예시 URL:

```
GET /broker/accounts
```

## 쿼리 파라미터

- 없음

## 요청 바디

- 없음

# 응답 형식

## 응답 헤더

```
HTTP/1.1 200 OK
Content-Type: application/json
```

## 응답 바디

```json
{
  "summary": {
    "accountCount":3,
    "totalMarketValue":15820000,
    "totalUnrealizedPnl":420000
  },
  "accounts": [
    {
      "accountId":25,
      "connectionId":15,
      "brokerId":1,
      "brokerName":"미래에셋증권",
      "accountNoMasked":"1234-****-5678",
      "accountName":"종합주식계좌",
      "accountType":"STOCK",
      "holdingCount":3,
      "totalMarketValue":8420000,
      "totalUnrealizedPnl":320000,
      "lastSyncedAt":"2026-07-29T15:00:03"
    }
  ]
}
```

계좌가 없다면:

```json
{
  "summary": {
    "accountCount":0,
    "totalMarketValue":0,
    "totalUnrealizedPnl":0
  },
  "accounts": []
}
```

### 속성

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `summary` | `object` | 필수 | 사용자의 전체 계좌 통합 요약 |
| `summary.accountCount` | `integer` | 필수 | 전체 계좌 수 |
| `summary.totalMarketValue` | `long` | 필수 | 전체 계좌의 주식 평가금액 합계 |
| `summary.totalUnrealizedPnl` | `long` | 필수 | 전체 계좌의 미실현 손익 합계 |
| `accounts` | `array` | 필수 | 사용자의 전체 계좌 목록 |
| `accounts[].accountId` | `long` | 필수 | 계좌 고유 ID |
| `accounts[].connectionId` | `long` | 필수 | 계좌가 속한 증권사 연결 ID |
| `accounts[].brokerId` | `long` | 필수 | 증권사 고유 ID |
| `accounts[].brokerName` | `string` | 필수 | 증권사 이름 |
| `accounts[].accountNoMasked` | `string` | 필수 | 마스킹된 계좌번호 |
| `accounts[].accountName` | `string` | 필수 | 계좌 표시 이름 |
| `accounts[].accountType` | `string` | 필수 | 계좌 유형 |
| `accounts[].holdingCount` | `integer` | 필수 | 현재 보유종목 수 |
| `accounts[].totalMarketValue` | `long` | 필수 | 계좌의 총 주식 평가금액 |
| `accounts[].totalUnrealizedPnl` | `long` | 필수 | 계좌의 총 미실현 손익 |
| `accounts[].lastSyncedAt` | `datetime` | 선택 | 해당 증권사 연결의 최근 동기화 시각 |
