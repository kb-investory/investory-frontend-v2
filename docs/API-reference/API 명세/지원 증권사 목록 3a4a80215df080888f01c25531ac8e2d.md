# 지원 증권사 목록

Method: GET
URL: /broker/providers
도메인: 계좌
상세 설명: Investory에서 지원하는 증권사 목록

### `GET /api/broker/providers`

지원 증권사 목록

### **요청 헤더**

```json
Authorization: Bearer {accessToken}
```

### URL 파라미터

- 없음

### 쿼리 파라미터

- 없음

### 요청 바디

- 없음

## 응답 형식

### 성공 응답

```json
200 OK
Content-Type: application/json
```

```json
{
  "providers": [
    {
      "brokerId":1,
      "brokerCode":"MIRAE",
      "brokerName":"미래에셋증권"
    },
    {
      "brokerId":2,
      "brokerCode":"KIWOOM",
      "brokerName":"키움증권"
    }
  ]
}
```

### 응답 속성

| 속성 | 자료형 | 설명 |
| --- | --- | --- |
| `providers` | `array` | 지원 증권사 목록 |
| `brokerId` | `long` | 증권사 내부 식별자 |
| `brokerCode` | `string` | 증권사 내부 코드 |
| `brokerName` | `string` | 화면에 표시할 증권사 이름 |

`isActive = true`인 증권사만 반환하면 되므로 응답에 `isActive`를 굳이 넣지 않아도 된다.
