# 단일 계좌 상세 조회

Method: GET
URL: /broker/accounts/{accountId}
도메인: 계좌
상세 설명: 특정 계좌의 기본 정보와 보유현황 조회

# 요청 형식

## 요청 헤더

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |

## URL 파라미터

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `accountId` | `long` | 필수 | 조회할 계좌 고유 ID |

예시 URL:

```
GET /broker/accounts/25
```

### 속성

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `accountId` | `long` | 필수 | 계좌 고유 ID |
| `connectionId` | `long` | 필수 | 증권사 연결 고유 ID |
| `brokerId` | `long` | 필수 | 증권사 고유 ID |
| `brokerName` | `string` | 필수 | 증권사 이름 |
| `accountNoMasked` | `string` | 필수 | 마스킹된 계좌번호 |
| `accountName` | `string` | 필수 | 계좌 표시 이름 |
| `accountType` | `string` | 필수 | 계좌 유형 |
| `lastSyncedAt` | `datetime` | 선택 | 마지막 데이터 동기화 시각 |
| `summary` | `object` | 필수 | 계좌의 보유자산 요약 |
| `summary.holdingCount` | `integer` | 필수 | 현재 보유종목 수 |
| `summary.totalMarketValue` | `long` | 필수 | 총 주식 평가금액 |
| `summary.totalUnrealizedPnl` | `long` | 필수 | 총 미실현 손익 |
| `holdings` | `array` | 필수 | 최신 보유종목 목록 |
| `holdings[].securityId` | `long` | 필수 | 종목 내부 고유 ID |
| `holdings[].securityCode` | `string` | 필수 | 종목코드 |
| `holdings[].securityName` | `string` | 필수 | 종목명 |
| `holdings[].marketType` | `string` | 필수 | 시장 구분 |
| `holdings[].quantity` | `number` | 필수 | 현재 보유수량 |
| `holdings[].averageCost` | `number` | 필수 | 평균매입단가 |
| `holdings[].marketValue` | `number` | 필수 | 해당 종목 평가금액 |
| `holdings[].unrealizedPnl` | `number` | 필수 | 해당 종목 미실현 손익 |
| `holdings[].portfolioWeight` | `number` | 필수 | 계좌 내 해당 종목의 평가금액 비중 |
| `holdings[].snapshotDate` | `date` | 필수 | 보유현황 기준일 |
