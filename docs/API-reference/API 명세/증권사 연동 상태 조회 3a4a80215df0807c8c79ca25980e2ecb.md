# 증권사 연동 상태 조회

Method: GET
URL: /broker/connections/{connectionId}
도메인: 계좌
상세 설명: 특정 증권사 연결 상태 조회

# 요청 형식

## 요청 헤더

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |

예시: 

```
Authorization: Bearer {accessToken}
```

## URL 파라미터

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `connectionId` | `long` | 필수 | 조회할 증권사 연결 고유 ID |

예시 URL:

```
GET /broker/connections/15
```

## 쿼리 파라미터

- 없음

## 요청 바디

- 없음

# 응답 형식

## 응답 헤더

```
HTTP/1.1 200 OK
Content-Type: application/json
```

## 응답 바디

```json
{
  "connectionId":15,
  "brokerId":1,
  "brokerCode":"MIRAE",

  "connectedAt":"2026-07-29T14:30:00",

  "latestSync": {
    "syncBatchId":102,
    "syncStatus":"SUCCESS",
    "requestedAt":"2026-07-29T14:45:00",
    "completedAt":"2026-07-29T14:45:03",
    "errorMessage":null
  }
}
```

### 속성

| 속성 | 자료형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `connectionId` | `long` | 필수 | 증권사 연결 고유 ID |
| `brokerId` | `long` | 필수 | 연결된 증권사 고유 ID |
| `brokerCode` | `string` | 필수 | 증권사 내부 식별 코드 |
| `brokerName` | `string` | 필수 | 증권사 이름 |
| `connectionStatus` | `string` | 필수 | 증권사 연결 상태 |
| `connectedAt` | `datetime` | 선택 | 증권사 연결 완료 시각 |
| `lastSyncedAt` | `datetime` | 선택 | 마지막 동기화 완료 시각 |
| `latestSync` | `object` | 선택 | 가장 최근의 동기화 작업 정보 |
| `latestSync.syncBatchId` | `long` | 필수 | 최근 동기화 작업 고유 ID |
| `latestSync.syncStatus` | `string` | 필수 | 최근 동기화 상태 |
| `latestSync.requestedAt` | `datetime` | 필수 | 동기화 요청 시각 |
| `latestSync.completedAt` | `datetime` | 선택 | 동기화 완료 시각 |
| `latestSync.errorMessage` | `string` | 선택 | 동기화 실패 원인 |

동기화 이력이 없다면 `latestSync`는 `null`이다
