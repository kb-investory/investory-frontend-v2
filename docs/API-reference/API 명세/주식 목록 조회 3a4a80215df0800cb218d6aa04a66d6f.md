# 주식 목록 조회

Method: GET
URL: /market/securities
도메인: 주식

```
GET /market/securities
```

# 요청 형식

## 요청 헤더

| 속성            | 자료형   | 필수 | 설명                                    |
| --------------- | -------- | ---- | --------------------------------------- |
| `Authorization` | `string` | 필수 | `Bearer {accessToken}` 형식의 인증 토큰 |

## URL 파라미터

- 없음

예시 URL:

```
GET /market/securities?keyword=삼성&marketType=KOSPI&page=0&size=20
```

## 쿼리 파라미터

| 속성         | 자료형    | 필수 | 설명                        |
| ------------ | --------- | ---- | --------------------------- |
| `keyword`    | `string`  | 선택 | 종목명 또는 종목코드 검색어 |
| `marketType` | `string`  | 선택 | `KOSPI`, `KOSDAQ`, `KONEX`  |
| `page`       | `integer` | 선택 | 페이지 번호, 기본값 `0`     |
| `size`       | `integer` | 선택 | 페이지 크기, 기본값 `20`    |

## 요청 바디

- 없음

# 응답 형식

## 응답 헤더

```
HTTP/1.1 200 OK
Content-Type: application/json
```

## 응답 바디

```json
{
  "securities": [
    {
      "securityId": 101,
      "securityCode": "005930",
      "securityName": "삼성전자",
      "marketType": "KOSPI",
      "sectorName": "전기전자",
      "industryName": "반도체"
    }
  ],
  "page": 0,
  "size": 20,
  "totalElements": 1,
  "totalPages": 1
}
```

### 속성

| 속성                        | 자료형    | 필수 | 설명              |
| --------------------------- | --------- | ---- | ----------------- |
| `securities`                | `array`   | 필수 | 조회된 종목 목록  |
| `securities[].securityId`   | `long`    | 필수 | 종목 내부 고유 ID |
| `securities[].securityCode` | `string`  | 필수 | 6자리 종목코드    |
| `securities[].securityName` | `string`  | 필수 | 종목명            |
| `securities[].marketType`   | `string`  | 필수 | 시장 구분         |
| `securities[].sectorName`   | `string`  | 선택 | 업종명            |
| `securities[].industryName` | `string`  | 선택 | 세부 산업명       |
| `page`                      | `integer` | 필수 | 현재 페이지       |
| `size`                      | `integer` | 필수 | 페이지 크기       |
| `totalElements`             | `long`    | 필수 | 전체 종목 수      |
| `totalPages`                | `integer` | 필수 | 전체 페이지 수    |
