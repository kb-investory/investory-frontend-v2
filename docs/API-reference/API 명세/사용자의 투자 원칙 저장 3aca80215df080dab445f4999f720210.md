# 사용자의 투자 원칙 저장

Method: PUT
URL: /principles
도메인: 원칙

# 요청 형식

## 요청 헤더

```sql
{
  "Authorization": "Bearer {accessToken}"
}
```

## 요청 바디

### 속성 설명

| 속성명 | 타입 | 설명 |
| --- | --- | --- |
| `analysisRunId` | Long | 해당 투자원칙이 생성된 성향 분석 실행 ID |
| `principles` | Array | 저장할 투자원칙 목록 |
| `principles[].recommendationId` | Long | 선택한 AI 추천 원칙 ID (`직접 추가`이면 NULL) |
| `principles[].principleText` | String | 최종 적용할 투자원칙 문장 |
| `principles[].ruleJson` | Object | 자동 판단/시뮬레이션용 구조화 규칙 정보 |
| `principles[].sortOrder` | Integer | 화면 표시 순서 |

```sql
Request
│
├── Header
│   └── Authorization
│
└── Body
    │
    ├── analysisRunId
    │
    └── principles[]
        │
        ├── recommendationId
        │
        ├── principleText
        │
        ├── ruleJson
        │
        └── sortOrder
```

### JSON Schema

```json
{
  "analysisRunId": 1,

  "principles": [
    {
      "recommendationId": 1,
      "principleText": "한 종목의 투자 비중은 30%를 넘지 않는다.",
      "ruleJson": {
        "type": "MAX_POSITION_RATIO",
        "value": 30,
        "unit": "PERCENT"
      },
      "sortOrder": 1
    },
    {
      "recommendationId": null,
      "principleText": "투자 근거를 작성한 후 매수한다.",
      "ruleJson": null,
      "sortOrder": 2
    }
  ]
}
```

## 응답 바디

### 속성

| 속성명 | 타입 | 설명 |
| --- | --- | --- |
| `principleSetId` | Long | 새롭게 생성된 투자원칙 묶음 ID |
| `versionNo` | Integer | 저장된 투자원칙 버전 번호 |
| `setStatus` | String | 생성된 원칙 묶음 상태 (`ACTIVE`) |
| `message` | String | 저장 처리 결과 메시지 |

```sql
Response
│
├── principleSetId
│
├── versionNo
│
├── setStatus
│
└── message
```

```sql
{
  "principleSetId": 3,

  "message": "투자원칙이 저장되었습니다."
}
```
