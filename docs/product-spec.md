# Investory 서비스 기획 문서

> **"모든 투자에는 이유와 이야기가 있다."**

---

## 서비스 개요

| 항목          | 내용                                                                               |
| ------------- | ---------------------------------------------------------------------------------- |
| **서비스명**  | Investory                                                                          |
| **슬로건**    | 모든 투자에는 이유와 이야기가 있다.                                                |
| **핵심 타깃** | 투자 경험은 있지만 자신만의 판단 기준을 아직 체계화하지 못한 자기주도형 개인투자자 |
| **핵심 가치** | 기록 → 분석 → 원칙 수립 → 검증(시뮬레이션)의 선순환                                |

## 기능 1 — 투자 일지 작성

### 목적

단순한 손익 기록이 아닌, **왜 그 결정을 했는지**를 남기는 투자 일기.

### 작성 단위

- **1 일지 = 1 날짜**
- 하루에 하나의 일지를 작성합니다.

### 작성 항목

| 항목        | 설명                                   |
| ----------- | -------------------------------------- |
| 날짜        | 일지 대상 날짜                         |
| 시장 느낌점 | 오늘 시장 전반에 대한 자유 텍스트 감상 |
| 거래 내역   | 매수·매도 종목별 한 줄 근거            |

### 거래 내역 항목 (건당)

| 항목              | 설명                                     |
| ----------------- | ---------------------------------------- |
| 종목명 / 종목코드 | 거래 대상 종목                           |
| 거래 유형         | 매수 / 매도                              |
| 수량, 단가        | 거래 수량과 단가                         |
| 한 줄 근거        | 이 거래를 결정한 핵심 이유 (자유 텍스트) |

### 플로우

```
홈 → [일지 작성] 버튼
  → 날짜 선택
  → 시장 느낌점 입력
  → 거래 내역 추가 (종목 검색 → 유형/수량/단가/근거 입력)
  → [저장]
  → 일지 상세 페이지로 이동
```

---

## 기능 2 — 투자 일지 조회

### 목적

과거에 작성한 일지를 찾아보고 나의 투자 결정을 복기합니다.

### 조회 방식

- 날짜순 목록 (최신순 / 오래된 순)
- 종목 검색으로 해당 종목이 포함된 일지만 필터링

### 일지 상세

- 시장 느낌점 전문
- 거래 내역 목록 (종목, 유형, 수량, 단가, 근거)
- 해당 일자 기준 보유 손익 (현재가 기준 미실현 수익률)

## 기능 3 — 투자 성향 분석

### 목적

내 투자 데이터(일지)를 분석해 **나는 어떤 투자자인지** 6가지 축으로 유형화하고, 그 결과를 바탕으로 나만의 투자 원칙을 제안합니다.

---

### 3-1. 투자 성향 분석 — 6가지 축

| 축 번호 | 축 이름            | 설명                                           | 유형 예시              |
| ------- | ------------------ | ---------------------------------------------- | ---------------------- |
| 1       | **보유 기간**      | 평균적으로 얼마나 오래 종목을 들고 있는가      | 단기형 ↔ 장기형        |
| 2       | **매매 빈도**      | 얼마나 자주 거래하는가                         | 소극형 ↔ 적극형        |
| 3       | **손절 패턴**      | 손실 상황에서 어떻게 반응하는가                | 손절 신속형 ↔ 버티기형 |
| 4       | **집중 vs 분산**   | 소수 종목 집중 투자 vs 다수 종목 분산 투자     | 집중형 ↔ 분산형        |
| 5       | **추세 추종 여부** | 상승 추세에 편승하는가 vs 역발상 매수를 하는가 | 추세추종형 ↔ 역발상형  |
| 6       | **감정 개입도**    | 기록된 근거의 감정적 표현 비율                 | 감정형 ↔ 논리형        |

> 각 축마다 0~100점 구간으로 점수를 산출하고, 구간에 따라 유형명을 부여합니다.

---

### 3-2. 투자 원칙 도출

성향 분석 결과를 기반으로 **나만의 투자 원칙 초안**을 자동 생성합니다.

#### 원칙 구성 방식

```
성향 분석 결과 (6가지 축 유형)
  → 각 축 유형에 매핑된 원칙 후보군 선택
  → 상충되는 원칙 필터링
  → 나만의 투자 원칙 세트 (3~5개) 제안
```

#### 원칙 예시

| 성향 조합                    | 도출 원칙 예시                                                                  |
| ---------------------------- | ------------------------------------------------------------------------------- |
| 장기형 + 집중형 + 논리형     | "확신 있는 종목에 집중 투자하고, 단기 등락에 흔들리지 않는다."                  |
| 단기형 + 분산형 + 추세추종형 | "상승 모멘텀이 확인된 종목을 소량 분산 매수하고, 목표가 도달 시 즉시 익절한다." |
| 버티기형 + 감정형            | "매수 전 근거를 3가지 이상 명문화하고, 감정적 판단은 하루 숙려 후 결정한다."    |

## 기능 4 — 투자 시뮬레이션

### 목적

도출된 나만의 투자 원칙과 패턴이 **실제로 수익에 도움이 되었는가**를 과거 데이터로 검증합니다.

---

### 4-1. 투자봇 종류

| 봇 이름         | 설명                                                        |
| --------------- | ----------------------------------------------------------- |
| **나의 원칙봇** | 내 성향 분석으로 도출된 투자 원칙을 따르는 봇               |
| **대안 원칙봇** | 내가 선택하지 않은 원칙들로 구성된 봇 (내 원칙의 반대 전략) |
| **워런 버핏봇** | 가치 투자 원칙 기반 봇 (저PBR·저PER, 장기 보유)             |
| **피터 린치봇** | 성장주 발굴 원칙 기반 봇 (PEG 중심, 생활 속 종목 발굴)      |
| **랜덤봇**      | 매매 시점을 무작위로 결정하는 원숭이 봇                     |

> 유명 투자자봇은 추후 추가 가능한 확장 구조로 설계합니다.

---

### 4-2. 시뮬레이션 범위

- **대상 종목**: 내가 실제로 매수·매도한 종목에 한정합니다.
  - 경험 없는 종목을 포함하면 시뮬레이션의 의미가 희석되기 때문입니다.
- **기간**: 사용자가 시작일~종료일을 직접 지정합니다.

---

### 4-3. 시뮬레이션 플로우

```
시뮬레이션 진입
  ↓
[봇 선택] (복수 선택 가능, 최대 4개)
  ↓
[기간 선택] 시작일 ~ 종료일 지정
  ↓
[시뮬레이션 실행]
  ↓
  ┌─ 데이터 준비
  │   └─ 선택 기간 내 대상 종목의 일별 가격 데이터 로드
  │
  ├─ 각 봇별 매매 신호 생성
  │   └─ 봇 원칙에 따라 매수/매도/홀드 결정
  │
  └─ 수익률 계산
      └─ 시작 시 동일 초기 자본 가정 → 기간 말 평가액 산출
  ↓
[결과 화면]
  ├─ 봇별 수익률 비교 차트
  ├─ 기간 수익률 / 최대 낙폭(MDD) / 승률
  └─ AI 피드백 (2문장)
```

---

### 4-4. 결과 화면 구성

| 구성 요소        | 내용                               |
| ---------------- | ---------------------------------- |
| 수익률 비교 차트 | 기간 내 봇별 누적 수익률 라인 차트 |
| 성과 테이블      | 봇별 수익률 / MDD / 승률 수치      |
| AI 피드백        | 결과를 기반으로 한 2문장 코멘트    |

#### AI 피드백 예시

> "이 기간 동안 나의 원칙봇은 랜덤봇 대비 12%p 높은 수익률을 기록했습니다.  
> 손절 기준을 일관되게 적용한 점이 낙폭을 줄이는 데 주요하게 작용했습니다."

## 기능 간 데이터 흐름

```
[투자 일지 작성]
    │  거래 내역 (종목, 수량, 단가, 근거)
    │  시장 느낌점 (텍스트)
    ▼
[투자 일지 저장 (DB)]
    │
    ├──▶ [투자 일지 조회]
    │       └─ 날짜/종목 필터 조회
    │
    └──▶ [투자 성향 분석]
              │  거래 패턴 + 근거 텍스트 분석
              ▼
         [성향 유형 도출 (6축)]
              │
              ├──▶ 투자 원칙 제안 (3~5개)
              │
              └──▶ [투자 시뮬레이션]
                        │  봇 선택 + 기간 설정
                        ▼
                   [시뮬레이션 실행]
                        │
                        ▼
                   [결과 + AI 피드백]
```
